# VELOUR — фронт

Все экраны MVP собраны. Два регистра: герой — кинематограф (`CinematicHero`),
всё остальное — тихая роскошь: воздух, одна-две строки, кадр.

## Страницы

## Компоненты `components/velour/`

`Veil` — изображение под вуалью: в скрытном режиме blur, если кадр не `discreetSafe`; наведение/касание приоткрывает.
`ProductCard` — кадр + имя + намёк + «от». `SensoryScale` — пять точек и слово вместо прогресс-бара.
`Filters` — шкалы, слова, «да»; применяются сразу через `router.get(..., { only: ['products','active'] })`.
`CartSummary`, `QtyStepper`, `Field`, `Toast`, `Header` (счётчик, шторка на мобильных), `QuickExit`, `DiscreetToggle`.

## WebGL и видео

`three-scene.ts` — общий каркас сцен: один RAF, остановка вне вьюпорта и на скрытой вкладке,
сглаженный курсор, прогресс скролла, уборка за собой; при `prefers-reduced-motion` рисуется один кадр.
`ObjectStage` — объект из стекла, построенный процедурно (`LatheGeometry` + `MeshPhysicalMaterial`
с преломлением и иридесценцией), отражения из процедурного окружения в цветах бренда.
`MaterialField` — пять материалов каталога (латекс, силикон, стекло, сталь, масло) одним шейдером;
при смене параметры перетекают, а не переключаются.

`VideoField` + `EditorialFilm` — редакционный кадр. Видео грузится только когда секция в кадре
(источники подставляются в `<source>` по IntersectionObserver, до этого сеть не трогается),
всегда без звука, засыпает вне экрана и на скрытой вкладке, при `prefers-reduced-motion` остаётся
постером, а при любой ошибке уступает место шейдеру. Съёмка приводится к бренду не в файле,
а слоями: обесцвечивание + бордо `multiply` по теням + золото `soft-light` по светам.
Файлы — `public/media/editorial.{mp4,webm}` и постер, звук вырезан (700 КБ / 430 КБ / 42 КБ).

## Переход между страницами и курсор

`PageCurtain` — занавес из бордо в пустоту: проходит сверху вниз (620 мс), держит экран,
пока Inertia меняет компонент, и уходит за нижний край (900 мс). Длительности заданы в TS
и уходят в CSS переменными `--cover` / `--reveal`, чтобы таймеры и движение нельзя было
развести. Занавесу нужен свой `--ease-curtain` с ровным разгоном: у `--ease-cine` почти всё
движение уложено в первую треть, и переход казался рваным. Между снятием `transition: none`
и сдвигом отдаётся кадр — иначе браузер видит только конечное положение и ставит его
мгновенно. Тот же занавес снимается один раз при жёсткой загрузке.

`Cursor` — кольцо с инерцией и золотая точка внутри. Над ссылкой кольцо растёт и золотится,
над `[data-magnetic]` притягивается к центру кнопки и тянет её за собой, над `[data-cursor="lens"]`
разрастается в лупу с перекрестием, в полях ввода прячется и возвращает системную каретку.
Монтируется только при `pointer: fine`; касание и `prefers-reduced-motion` не трогает вовсе.

## Микроанимации (`app.css`, `@layer components`)

Все — отклик на действие, ни одной «на скролл»:

- `.sheen` — блик шёлка проходит по кадру при наведении;
- `.cursor-glow` — тёплое пятно света идёт за курсором по галерее товара (`--mx/--my`);
- `.breathe` — кадр медленно дышит в масштабе;
- `.thread` — золотая нить растёт из-под текста ссылки;
- `.btn-gold` — заливка поднимается снизу, как уровень жидкости;
- `.stagger` — единственный вход страницы: дети всплывают по `--i`;
- `.scale-dot` — точки шкалы зажигаются и светятся;
- `.curtain` — мобильное меню опускается занавесом из бордо.

`prefers-reduced-motion` отключает всё разом.

## Правила, которых держались

- Токены только из `@theme`; ни одного hex в TSX кроме палитры шейдера.
- Нет tracked-out ALL-CAPS эйбрау, стрелок в кнопках, нумерации 01/02/03, серых карточек с тенью.
- Ни одного откровенного изображения или слова: желание через материал, температуру, вес и свет.
- Данные — только из Inertia props, типы — `types/catalog.d.ts` и `types/velour.d.ts`.
