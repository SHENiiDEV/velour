# VELOUR — бэкенд

Собран целиком: каталог, корзина, оформление, платёжная абстракция.
Фронт получает данные только через Inertia props; вёрстка — следующий этап.

## Данные

`categories → products → variants`, `media` полиморфна, `carts/cart_items`,
`orders/order_items/payments`. Деньги — целые центы, никаких float.

**Сенсорные характеристики.** Значения живут в `products.attributes` (json) —
новый признак не требует миграции. Для фильтров `ProductObserver` зеркалит json
в плоскую `product_attributes` (`value_numeric` / `value_text`), поэтому
`Product::withAttribute('firmness', [4,5])` работает одинаково в MySQL и PostgreSQL.
Человеческие подписи («4 → плотно») берутся из `attribute_definitions`.

> Подводный камень: колонка называется `attributes`, а у Eloquent есть protected-свойство
> с тем же именем. Снаружи `$product->attributes` работает, внутри модели — нет.
> Поэтому в коде всегда `$product->sensory()`.

## Приватность в схеме, а не в интерфейсе

- `orders.is_discreet_packaging` — по умолчанию `true`, выключается только явным действием.
- `orders.statement_descriptor` — нейтральная строка в выписке, пишется в заказ на момент оформления.
- `media.is_discreet_safe` — можно ли показать кадр без blur в скрытном режиме.
- Корзина на cookie-токене: покупка без регистрации — часть приватности, а не удобство.
- Номер заказа `VLR-2026-000123` ничего не сообщает о содержимом.

## Домен

`CartService` — добавление, изменение, слияние гостевой корзины при логине
(слушатель события `Login` в `VelourServiceProvider`).

`CheckoutService::place()` — одна транзакция: `lockForUpdate` на каждом варианте
(гонка за последний экземпляр), снимки цен и названий в `order_items`, списание стока,
расчёт доставки, затем инициация оплаты. Переименование или удаление товара
не переписывает прошлые заказы.

`PaymentGateway` + `PaymentManager` — весь магазин знает только интерфейс.
Драйвер `manual` доводит checkout до конца без эквайера (оплата в статусе «ожидает»),
чтобы можно было тестировать и запускать витрину до подключения провайдера.
Webhook'и живут в `routes/webhooks.php` — отдельная группа без сессии, CSRF и age-gate.

## Что осталось на бэке

- Драйвер реального провайдера (CCBill / Segpay / Verotel) + проверка подписи в webhook.
- Письма: подтверждение заказа, смена статуса.
- Админ-CRUD каталога (сейчас наполнение — сидером).
- Промокоды и налоги (поля `discount_cents` / `tax_cents` уже есть).
