# Импорт каталога из WooCommerce

```bash
php artisan velour:import-woo storage/app/woo.csv --currency=GBP --dry-run   # посмотреть
php artisan velour:import-woo storage/app/woo.csv --currency=GBP             # записать
```

Команда идемпотентна: товар опознаётся по паре `source` + `source_id` (ID из Woo),
повторный запуск обновляет цену, остаток, описание и галерею, а не плодит дубли.

## Ключи

| Ключ | Что делает |
|---|---|
| `--currency=GBP` | Валюта цен в файле. По умолчанию `config('velour.currency')` — **EUR**. Выгрузка из британского магазина почти наверняка в фунтах: без этого ключа цены переедут как евро. |
| `--dry-run` | Разобрать файл и показать итог, ничего не записывая. |
| `--draft` | Положить всё в черновики — витрина их не покажет, пока не проверишь. |
| `--fallback=Other` | Куда девать товары без вменяемой категории. |
| `--discreet-safe` | Считать импортированные кадры безопасными для скрытного режима. По умолчанию нет: предметные фото производителя размываются. |

## Как ложатся данные

| Woo | VELOUR |
|---|---|
| `ID` | `products.source_id` (+ `source = woocommerce`) |
| `Name`, `Description` | `name`, `description` (HTML → текст с абзацами) |
| первое предложение описания | `tagline`, если оно короче 140 символов; иначе пусто |
| `Regular price` / `Sale price` | `price_cents` (скидочная цена в приоритете) |
| `Categories` с `>` | дерево `categories` с `parent_id`; берётся первая категория товара |
| `SKU`, `Stock`, `Weight (kg)` | один вариант по умолчанию: `sku`, `stock`, `weight_g` |
| `Images` через запятую | `media` в порядке из файла, `is_discreet_safe = false` |
| атрибуты `brand`, `UPC`, `MPN` | `products.brand`, `gtin`, `mpn` |
| `Published`, `Is featured?` | `status`, `is_featured` |

**Чего в выгрузке нет и что мы не выдумываем:** сенсорных характеристик
(упругость, поверхность, вес в руке, тишина) и состава материалов. Поля остаются
пустыми, поэтому у импортированных товаров не показываются шкалы ощущений,
а обещание body-safe выводится только там, где состав действительно указан.
Заполнять это нужно руками — это и есть та часть, где VELOUR отличается от донора.

Вариативные товары Woo (`Type = variable` + строки `variation`) пока пропускаются
с предупреждением: их варианты живут отдельными строками и требуют отдельной ветки логики.

## Подводные камни этой конкретной выгрузки

- **416 товаров, все `simple`** — разобрались без потерь, ни одной строки не пропущено.
- **Картинки ссылаются на `oh-yes-toys.co.uk`.** Хотлинк на чужой хостинг: файлы могут
  исчезнуть или отдавать 403 в любой момент, и юридически это не твои файлы.
  До запуска их нужно перекачать к себе и заменить `media.path` на локальные.
- **Цены, похоже, в фунтах** — не забудь `--currency=GBP`, иначе 54.99 GBP станут 54.99 EUR.
- **9 товаров без категории** (`Uncategorized` / `Merged Term Name`) уедут в `Other`.
- **Названия и фото — чужого магазина.** Описания написаны производителями; для VELOUR
  их стоит переписать своим тоном, иначе тексты будут спорить с брендом.
- **Права на контент.** Тексты и фотографии принадлежат правообладателям. Перед публикацией
  убедись, что у тебя есть право их использовать — обычно это решается договором с дистрибьютором.
